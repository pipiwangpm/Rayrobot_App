新建任务

本地模式：只能从设备已缓存的任务与素材组合并立即下发（无云端库、不可上传/编排）。

① 选择目标设备（内网可达 · 有能力清单）

② 从 该机 缓存组合（任务 / 素材）

③ 立即下发

提交即本地判定占用：设备空闲 → 执行中；被占用/不可达 → 拒绝该次执行（无排队）。

本地组合不产生云端任务记录；执行留痕存机器人本地。切换回云模式可在云端查看完整记录。

任务有四类：脚本 / 广告 / 跟随 / 口播；脚本与素材由运营在 Web 编排，App 选择并绑定设备后由调度中心执行。口播任务在 App 内输入一段文字即可。遥操、自主交互属于设备模式，在「设备控制」页使用，不在这里创建。

下发方式

提交即立即下发：下发时检查设备占用——设备空闲 → 直接进入执行中；已被占用 / 离线 → 拒绝该次执行（执行记录记失败并注明原因）。无排队 / 待执行，再次执行请在任务中心操作。

提交后立即由调度中心下发；网络瞬时失败自动重试 1 次；设备占用 / 离线的拒绝不重试并记为失败。
