任务怎么下发

下发即判定 · 占用即拒 · 不排队

四类任务

脚本任务 —— 脚本 × 设备角色，一个角色可绑多台；广告任务 —— 每台设备一组素材播放列表（按序循环）；跟随任务 —— 固定引导员 / 目标跟随；口播任务 —— 输入一段文字，用选定音色语音播报（只发声、不触发动作）。

下发即判定（无排队 / 无待执行）

设备空闲 → 执行中；设备被其它任务占用 → 拒绝该次执行；设备离线 → 拒绝。被拒绝会记一条失败记录并写明原因，不排队等待；首版不做定时 / 周期排期。

任务 = 任务 × 执行记录

点卡片可展开历史执行记录（最新在前，含状态、时间、耗时、设备、失败原因）；「再次执行」同样按上述规则判定，也可能被拒绝。

云模式

任务与执行记录由云端聚合（顶部今日总览：成功 / 执行中 / 完成率）；新建任务可绑设备后立即下发。

本地模式

只展示设备已缓存的任务与素材，可轻量组合后本地下发（占用即拒）；本地不可上传素材，需先在云模式或 Web 预下发到设备缓存。

编辑边界

App 内只做「选类型 → 配置 → 绑设备 → 立即下发」；脚本与素材的编辑 / 上传在 Web 端完成。
